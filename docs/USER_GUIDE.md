# 使用者操作手冊（0.9.28）

## 最簡單的使用方式

1. 先看「今天最值得先看」。
2. 點上方你有興趣的分類，例如「新番動漫」、「Netflix 新劇」或「Disney+ 新劇」。
3. 想追的作品按「加入想看清單」，再點上方「我的想看清單」就能找回。

新番動漫、Netflix 新劇和 Disney+ 新劇各自分開。資料以公開消息搜尋整理，不保證涵蓋平台全部片單；台灣上架日期以平台官方公告為準。卡片有來源附圖才會顯示圖片，破圖會自動移除。

「每日充電」每天提供三則簡短原創提醒，每則都有一個今天能試的小行動；按「收藏這個提醒」可在「我的想看清單」回看。它不是名人語錄，也不是心理諮商。

## 看懂內容

「僅取得標題 · 未讀取全文」表示沒有足夠內文，不能當作全文摘要。「來源提供的摘要」也不等於系統完成事實查核。

搜尋熱度與社群討論只表示關注訊號。未翻譯英文貼文仍不進繁中首頁。首頁提供「翻成繁中」原文連結，不保證翻譯網站能讀取所有來源。

分類在來源有三個不同候選時顯示三則；來源失敗或沒有足夠資料時不硬塞。首頁精選與分類可能出現同一篇，收藏狀態會一致。

## 收藏、隱藏與主題偏好

- 「收藏這篇」只收藏這篇；點頁首「我的想看清單」找回或取消。
- 新番／串流劇按「加入想看清單」；同一入口可查看及取消收藏。
- 每張內容預設只露出「看原文」和主要收藏動作；要隱藏、調整多看／少看時，再點「更多」。
- 「隱藏這篇」只隱藏同一篇文章，不影響另兩篇。可在收藏與偏好區恢復。
- 「多看『Codex』」或「少看『Codex』」調整該主題在分類清單的順序；往後報告若取得同主題內容，會繼續套用。
- 主題偏好不會替同主題其他文章加框，也不會增加雲端抓取量。辨識不到具名主題時，只提供單篇操作。
- 偏好清單可逐項取消或全部清除；收藏不受清除偏好影響。

資料只存在這台裝置的瀏覽器；換手機、清除網站資料後會遺失。若瀏覽器不允許儲存，頁面會提示只暫存到本次關閉。舊版「有興趣」加框紀錄不自動轉成新主題偏好。

## 更新

每小時 :17、:47 安排更新，GitHub 免費排程可能延遲，不保證準時完成。超過 90 分鐘的報告會提醒檢查。

- 「檢查最新頁面」重新取得已部署報告，不重新抓資料。
- 「手動產生新報告」開啟 GitHub Actions，再按 **Run workflow** 執行。

新增數以最近 500 個文章指紋比較；同內容重跑不算新增。首次沒有紀錄時顯示「尚未建立可比較紀錄」；下一輪才開始比較。最後新增／改動是報告內容變動的時間，不是新聞事件發生時間。

## 電腦使用

雙擊 `start.bat` 抓即時資料；雙擊 `start_demo.bat` 看離線範例。也可使用 `python main.py --live` 或 `python main.py --demo`，產出在 `reports/`。

興趣設定在 `config/interests.json`。YouTube 必須先填 `config/youtube_channels.json` 的頻道 ID，只追蹤選定頻道，不是全站熱門排行榜。可用分類以興趣設定的名稱為主，例如「遊戲與電競」或「生活流行」。

## 資料狀態

- 來源正常：至少三個來源，且無來源錯誤。
- 部分來源受限：仍有至少三個來源，但部分平台失敗。
- 資訊來源不足：只有一到兩個來源。
- 資料不足：沒有可用情報。Live 不會用 Demo 資料冒充。
